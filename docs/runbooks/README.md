# Runbooks

The [Phase 1 Console setup guide](console-option-a-setup.md) is an approval-gated checklist, not evidence that resources exist.

For the MVP, add only concise response notes for signing failure, unexpected Transcribe usage, final-save failure, DynamoDB/API failure, and cleanup. Recorded upload, S3 export, derived-feature, production on-call, and load-test runbooks are deferred.
